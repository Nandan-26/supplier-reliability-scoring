# AI Prompt Documentation

This directory contains the AI prompts used during the development of the Supplier Reliability Scoring Engine.

## Purpose

The prompts document how AI assistance was used during different development stages, including database design, synthetic data generation, debugging, validation, and testing.

## Original Prompts

| File | Development Stage |
|---|---|
| `01_database_schema.md` | Database schema and testing |
| `02_synthetic_data_generator.md` | Synthetic data generator |
| `03_generator_corrections.md` | Generator debugging and validation |

## Transparency

The original prompts are preserved as provided. Any subsequently reconstructed prompts will be explicitly identified as reconstructed rather than presented as verbatim historical records.

AI was used as a development assistant. Generated suggestions and code were reviewed, tested, and integrated into the project as appropriate.
